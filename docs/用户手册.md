# 单位产品能耗对标软件（首版正式版）

## 适用范围

首版为 Windows 10/11 x64 离线单机程序。标准库固定包含用户确认范围内的 46 项当前强制性能耗限额标准，共 702 条当前指标；另附 GB 29141-2012 历史版本用于历史评价。702 条当前规则已全部确认发布。GB 29141-2012、GB 29437-2012、GB 29441-2012 已由 GB 29141-2024 替代；GB 29447-2022 已由 GB 29447-2026 替代，并新增 GB 47834-2026、GB 47835-2026。当前包保留 7 条原文缺级或非单调警告，软件不会猜测补值。

## 启动与数据目录

运行 `dist/UEBench/UEBench.exe`。程序首次启动会在本机应用数据目录建立 SQLite 数据库、日志、备份和标准包目录，不读取原始 G 盘路径。开发验证时可通过环境变量 `UEBENCH_DATA_DIR` 指定数据目录。

## 新建评价

1. 在“新建评价”选择标准和产品/工序。评价日期由软件读取电脑真实日期；可切换历史或未来标准，切换后软件会显示提示，评价日期早于标准实施日期或选择已替代标准时会阻止/警告正式判定。
2. 选择“直接录入”填写已经核算的单位产品能耗，或选择“明细计算”填写能源、产量、分摊比例和适用条件。
3. 单位必须与规则定义一致；布尔条件填写“是/否”。缺少必填数据、除数为零或条件无法确定时结果为“不完整”，软件不会猜测。
4. 计算后按指标分别显示基础限额、修正后限额、实际值、等级和原文依据。软件不生成产品总体等级。

在“标准库”中选中一项标准后，下方会展开该标准的产品/工序、指标、单位、三级限额、适用说明和页码/条款/表号；点击“打开标准原文”可打开随标准包安装的 PDF。

## Excel

“Excel导入”页面提供固定模板。不得改动工作表名称、列名或 `template_version`。导出文件包含结论、输入、计算轨迹、标准依据和校验日志；导出值来自同一次软件计算，不在 Excel 内重复判级。

## 标准包与发布门槛

`.uebench` 标准包使用签名和 SHA-256 校验。安装前自动备份，失败自动回滚。规则确认表中每条规则须由复核人填写日期并选择“同意发布”，经确认后才能由 `reviewed` 发布为 `published`；退回项不会参与正式计算。

## 备份与审计

系统维护页可创建/恢复备份。评价采用软删除，标准包安装、导入、导出、计算和删除均写入本地审计日志。历史评价保存当时的规则快照，升级标准包不会改写历史结果。
