## 2. 首版范围与四种生产模式

水泥首版仅接收同一统计期、同一生产线的**原始燃料、电量、产量 DETAIL 明细**；不接收直接填写单位能耗的正式请求（V1.2 Q4=C），不要求建设属性，不输出法定限定值/准入值符合性（Q3=B）。五个可判级指标彼此独立，不合成“熟料总等级”或企业总等级。水泥综合电耗 `W_s` 是式（7）中间量，展示及追踪但不另造表外等级。

| 生产模式 | 水泥综合能耗 `E_s` | 熟料综合能耗 `E_sh` | 熟料综合煤耗 `e_sh` | 熟料综合电耗 `W_sh` | 制备工段电耗 `W_sg` |
|---|---|---|---|---|---|
| 自产熟料并生产水泥 | 适用 | 适用 | 适用 | 适用 | 适用 |
| 部分外购熟料生产水泥 | 适用；式（8）用本企业 `e_sh` | 适用 | 适用 | 适用；式（7）用本企业 `W_sh` | 适用 |
| 仅生产熟料 | 不适用 | 适用 | 适用 | 适用 | 不适用 |

粉磨站在 V1.2 §17.3 中允许另行展示 `E_s` **扩展参考**的可能性，但本首版不启用该可选范围，不把它混入粉磨站正式结果、保存完整性或 Word。日后若要启用，先独立确认展示与来源，再改设计和验收。仅熟料模式和粉磨站不填不适用的生产链，不能以零代替“没有适用指标”。海拔扩展口径只作用于 V1.2 指明的表1/表2相关 3 级阈值；表3 `W_sg` 不修正，海拔恰为 1500 m 不触发。

## 3. Canonical Input、单位与前置校验

一条评价请求绑定一个标准版本、统计期、评价厂区、生产模式和生产线标识。多线企业按线分别计算；不把各线先混成一条企业总量。字段业务名、含义、单位与选项取 V1.2 §23，UI 和后续 Word 使用同一描述源。Canonical 保留输入的十进制词法值、单位、填/未填状态及来源；所有正式计算用 Decimal，不以显示位数或 Python float 参与比较。

| 输入组 | 核心数据与单位 | 设计校验及依赖 |
|---|---|---|
| 基本信息 | 评价周期、四选一生产模式、厂区、生产线；海拔 m、环境气压 `P_H` Pa | 同一请求的燃料/电量/产量须同统计期；海拔严格大于 1500 m 且适用动态 3 级阈值时要求气压与来源；不增加建设属性必填 |
| 熟料生产 | 自产产量 `P_sh` t；各燃料量 `m_i` kg、低位热值 `Q_idw` kJ/kg、标准煤热值 `Q_BM` kJ/kgce；`w_sh`、`w_he`、`w_0` kW·h | 适用熟料链时 `P_sh>0`；`Q_BM=29307.6`及来源由Rule固化，规范引用核证见§9.1，不要求用户逐次填写；净余热与扣减边界按 V1.2 §9、§11 核 |
| 四项窑系统扣除 | 协同处置燃料、替代燃料各 tce；协同处置用电、替代燃料用电各 kW·h | 均默认**空白**，不预填 0；空白在追加扣除计算中按 0，不能解释为现场无该活动。燃料 tce 分项合计后乘 1000 转 kgce；电量另行合计为 `w_fc`，不混单位、不交叉重复扣。录入值非负、有限，扣除不得超过已包含的原始对应总量 |
| 水泥生产 | 水泥产量 `P_s` t、实际用于本期水泥的熟料 `P_shx` t、熟料配比 `g` %、制备系统燃料 `e_h` kgce，`w_fm/w_m/w_g/w_fz/w_sg` kW·h | 适用水泥链时 `P_s>0`；`P_sh` 与 `P_shx` 分开输入、可不相等，不以自产量推定实际耗用量。用户输入 `g=75` 表示 75%，计算内核变为 `g/100=0.75`；不要求用户输入 0.75 |

UI 普通标签不能用 placeholder 代替；四扣除字段可用 V1.2 已批准的浅色提示“若已扣除，则不填”。错误指向字段并给可定位汇总，计算中明确加载、成功或错误及恢复动作，不把 Warning / Info 无依据升级为阻断。直接调用 Application 与 GUI 使用相同必要性校验；绕过界面提交 DIRECT 水泥正式请求必须被拒绝。

## 4. 计算依赖、修正与分线分摊

设计以 V1.2 §9–18、§22 的正式式（2）—（9）和已批准软件解释构建**有向依赖图**，不从旧 `data/definitions/gb-16780-2021.json` 的泛化 `per_unit` 推导新公式。先计算熟料原始燃料折标、净燃料、余热和净电量，再得 `e_sh`、`W_sh`、`E_sh`；水泥端以 `P_shx` 和净 `W_sh` 求 `W_s`，再以净 `e_sh`、`g/100`、`e_h/P_s`、`0.1229W_s` 求 `E_s`；`W_sg=w_sg/P_s` 独立。部分外购的式（8）取 `e_sh`，不能取 `E_sh`；全部外购的式（7）`W_sh=0`、式（8）`e_sh=0`仅是对应公式边界，本首版粉磨站仍只正式评价 `W_sg`。四扣除在熟料源头各扣一次，不在式（5）（7）（8）重复整体扣除。

| 顺序 | 中间量 / 正式值 | V1.2 对应算式与单位 | 适用与追踪 |
|---|---|---|---|
| 1 | `e_fc`、`w_fc` | `e_fc=1000×(协同燃料tce+替代燃料tce)` kgce；`w_fc=协同用电+替代燃料用电` kW·h | 保留四原值和未填状态；仅原始总量尚含该部分时追加扣除 |
| 2 | `K` | 海拔≤1500 m 时 1；海拔>1500 m 时 `1.179−0.211×P_H/101325` | `P_H>0`，不按海拔估算气压；仅调整适用的 3 级阈值，不调整实际值 |
| 3 | `E_he` | `0.1229×(w_he−w_0)/P_sh` kgce/t（正式式（3）） | 余热只扣一次；净发电负值的处理实施前核证 |
| 4 | `e_sh` | `Σ(m_i×Q_idw)/(Q_BM×P_sh)−E_he−e_fc/P_sh` kgce/t | 前两项为正式式（2）/（3）；末项是用户采纳的 2019 参考分项扣除，不冒称 2021 式（2）明文 |
| 5 | `W_sh` | `(w_sh−w_fc)/P_sh` kW·h/t | 2021 式（4）基础量加用户采纳的 2019 参考扣电结构；`w_sh−w_fc≥0` |
| 6 | `E_sh` | `e_sh+0.1229×W_sh` kgce/t（正式式（5）） | 使用已净扣的两个熟料值，不再整体扣 |
| 7 | `W_s` | `[w_fm+W_sh×P_shx+w_m+w_g+w_fz]/P_s` kW·h/t（正式式（6）（7）） | 中间量、无表外等级；部分外购用本企业 `W_sh`，`P_shx` 不替换为 `P_sh` |
| 8 | `E_s` | `e_sh×(g/100)+e_h/P_s+0.1229×W_s` kgce/t（正式式（8）） | 部分外购用本企业 `e_sh`（Issue 001）；不使用 2019 C.7 的 `E_sh` |
| 9 | `W_sg` | `w_sg/P_s` kW·h/t（正式式（9）） | 表3独立统计；窑系统四扣除不传入 |

分项扣除的来源层级、单位转换及式（8）的百分数转换必须随结果记录，不能只留下最终五个数。

每个指标记录基础阈值、最终有效阈值、修正因子、实际值、等级、来源及中间量。水泥综合能耗有效阈值：`L1=80+1.10(g-75)`，`L2=87+1.15(g-75)`，`L3=94K+1.20(g-75)`；`g` 在此是百分数数值，3 级先海拔后配比（Issue 003），不改为 `(94+1.20(g-75))K`。表2熟料三指标仅按 V1.2 修正 3 级阈值，表3不修正。等级比较遵循 `≤` 与全值精确值；有效值完成该三级体系比较而超过 3 级时，按[统一判定规范 §10](统一判定规范.md)的 Owner 共同软件标签显示“未达3级”，底层保留既有 `NOT_QUALIFIED`，不改 V1.2 冻结正文中旧示例文字，也不创造第四等级。

| 可判级指标 | 1级上限 | 2级上限 | 3级最终上限 |
|---|---:|---:|---|
| `E_s` kgce/t | `80+1.10(g−75)` | `87+1.15(g−75)` | `94K+1.20(g−75)` |
| `E_sh` kgce/t | 100 | 107 | `117K` |
| `e_sh` kgce/t | 94 | 100 | `109K` |
| `W_sh` kW·h/t | 48 | 57 | `61K` |
| `W_sg` kW·h/t | 26 | 29 | 34 |

多线首版按 V1.2 §21 逐线统计。若共用系统的能耗服务于**同一产品**的多线，记录原始共用量、对应产品、参与线集合及各线同期产品产量，按 `分摊量_i = 共用量 × 本线该产品产量 / 参与线该产品产量合计` 分到各线；保留共用量、分母、份额、分摊后量、来源、Decimal 运算精度及`原始共用量−各线分摊合计`残差。有限精度除法不保证逐字节零残差；不得隐式修约、加 epsilon 或任意把尾差丢给末线。保存权威原始输入、明确公式、Decimal 28派生结果和真实残差。普通有限精度残差不阻保存，不伪称零残差；不引入Fraction、epsilon、隐式尾差分配或末线补差。若共用系统跨熟料/水泥产品、产量口径或边界不明，不能猜一个分母或把同一量记入两条链；该部分标待核证并阻断依赖它的正式保存，允许不受影响指标预览。不做企业总等级，也不把多个线记录合并为一条正式结果。

## 5. 指标状态、部分预览、保存与 Word

每个指标先按模式标 `NOT_APPLICABLE` 或适用。适用指标按自身依赖分别得到“完整已判级（1/2/3级或未达3级）”“输入不完整”或“有数据但无法判定”；错误输入在计算前给具体校验错误。这里是**指标计算状态设计**，不是中央五态标准支持状态，也不为生产系统新增公共状态枚举。局部缺失仅影响依赖它的指标；其余完整指标照常显示实际值、阈值和等级。超出 3 级是完整有效等级，`NOT_APPLICABLE` 不算缺项。

V1.2 Q1=A：只要任一**适用**指标不完整或无法判定，结果页只能显示“部分计算预览”及未完成原因；**Application 保存前**再次检查完整性，拒绝正式评价 Record，不能仅隐藏 UI 保存按钮。仅所有适用指标均完整判级时才可保存一条正式记录，包含本次 Canonical 原文、适用性、四扣除空白状态及扣前/扣后、分线分摊、有效阈值、Numeric 与 Rule 身份、Issue 001/003 解释属性和结果快照。历史记录不因新规则重算；当前选煤历史兼容保持。

水泥 Word 是 Stage C/D 的**待实现、待验收**能力，不沿用只适用于选煤单项的现有模板充当已支持。将来仅从**已保存、完整、有效的水泥记录快照**投影五指标中适用项、来源及解释；部分预览、无法判定、未保存内容不提供正式 Word 报告。页面和 Word 的字段名、单位、结果及说明来自批准映射与同一描述源；允许布局差异，不允许两套业务结论。Excel 工作簿本轮不设计交付或开放；后台旧 Adapter 的安全能力不因此变更。

## 7. 独立 Golden Candidate 与验收矩阵

Golden 预期须由 V1.2、标准条款和手算证据**独立推导**，不得用新 Calculator 的输出回填。至少准备四模式各一组、五指标各 1/2/3/未达3级、阈值 `T−δ/T/T+δ`、海拔 1500/高于1500、`g=75`及非75、Issue 001/003、四扣除空白/零/重复/超过原量、`P_sh≠P_shx`、多线同产品分摊与跨产品不明、部分预览和保存拒绝、NOT_APPLICABLE、无法判定、历史快照、Word 与 UI 同源。2019稿 C.1/C.3 仅标用户采纳的技术参考，C.7 不进入正式式（8）。

**手算候选 A（待独立复核来源后冻结）**：自产熟料并生产水泥，厂区海拔≤1500 m，故 `K=1`；`P_sh=1000 t`，原燃料 100000 kg 且 `Q_idw=Q_BM`，余热净电量 10000 kW·h，协同/替代燃料各 1 tce；`w_sh=50000 kW·h`，两项电扣各 1000 kW·h。条件计算得余热煤耗扣减 `1.229 kgce/t`、`e_sh=96.771 kgce/t`（2级）、`W_sh=48 kW·h/t`（1级）、`E_sh=102.6702 kgce/t`（2级）。再取 `P_s=1000 t`、`P_shx=750 t`、`g=75`、`w_fm=20000`、`w_m=1000`、`w_g=1000`、`w_fz=2000` kW·h、`e_h=1000 kgce`，则 `W_s=60 kW·h/t`（中间量，不判级）、`E_s=80.95225 kgce/t`（2级）。`w_sg=23000 kW·h` 得 `W_sg=23 kW·h/t`（1级）；五指标完整可进入保存候选。此例的 `Q_BM` 来源已由§9.1核证；余热定义与每个扣除归属仍须由独立复核确认，不能先写成已批准 Golden。

**对照候选 B**：仅移除 A 的 `w_sg`，`W_sg` 因依赖缺失不可判，其余四项仍显示完整结果；整个请求仅作部分预览，Application 拒绝正式保存和 Word。另需仅熟料模式三指标完整保存、粉磨站仅 `W_sg` 完整保存、部分外购 `e_sh/E_sh` 区分、双修正 `L3=94K+1.20(g-75)` 与错误候选 `(94+1.20(g-75))K` 区分，以及同产品两线分摊守恒的独立期望。

### 9.1 参数来源核证（2026-10-29）

`Q_BM` 不采用无依据的29307默认值。[国标官方登记](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=53D1440B68E6D50B8BA0CCAB619B6B3E)确认GB/T2589—2020现行、2021-04-01实施；其§8.2以国际蒸汽表卡定义29307.6 kJ/kgce。该值另获[国家发改委公开技术文件](https://www.ndrc.gov.cn/yjzxDownload/20220726fj6.pdf)援引GB/T2589—2020支持。29307来自旧2008版，不能因旧软件常量延续便默认适用于2021水泥。2021水泥规范性引用已核为不注日期，采用现行2020版参数并将依据固化到Rule/快照，普通用户不必每次填写来源。统计制度20℃卡的29271.2属于另一口径，不自动覆盖水泥标准。

余热净量为负时，现有批准映射没有授权截断或取绝对值；首版受限处理为拒绝依赖该量的完整正式保存，保留无关指标预览，并明确这是软件防误录处理，不冒称标准明文。若后续确认真实业务允许该净值，再提供证据并独立审查，不改变冻结映射。
