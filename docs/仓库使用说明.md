# ECQuota-Insight 源码使用说明

> 当前产品目标：下一正式版完整支持 GB 29446—2019。总体路线见 [`参考标准开发路线.md`](../参考标准开发路线.md)。
> 本文中的历史盘符、数量与发布记录仅为当时记录；当前开发源码以实际 `main` SHA 为准。

## 环境与启动

Windows 10/11 x64，Python 3.13；程序包名仍为uebench。

```powershell
git clone https://github.com/adgo07/ECQuota-Insight.git
Set-Location ECQuota-Insight
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m uebench.main
```

首次启动可能没有标准。在系统维护页安装可信的签名 `.uebench` 标准包；规则JSON不能直接替代签名安装包。查看原文要求包内包含对应哈希的PDF。本仓库不上传标准原文、签名私钥、运行数据库或旧版EXE；公共验证密钥不是私钥。

## 目录

- src/uebench/domain：正式Decimal计算；application：应用用例；infrastructure：数据库、Excel与签名包；ui：Qt界面。
- data：正式规则；standards/development/scope-63：唯一开发基线，scope-65仅供历史对照。
- tests：回归测试；tools/scripts：校验及发布工具；docs：规范、操作说明及历史记录。

## 测试与发布前提

纯源码测试无需本机发布ZIP：

```powershell
.\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider --ignore=tests/test_frozen_release.py --basetemp work/pytest-source
.\.venv\Scripts\python.exe tools/check_published_rules.py --data-dir data/definitions --scope data/scope-44.json
.\.venv\Scripts\python.exe tools/build_development_manifest.py --check
```

完整测试要求已有 dist/release/UEBench-0.1.0-win-x64.zip，然后运行：

```powershell
.\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider --basetemp work/pytest-full
```

2026-09-26独立验收303项通过，包含本机旧ZIP的DLL安全检查；它不证明新版EXE已构建。不得把排除冻结包测试的源码回归称为完整测试。

发布需安装 `.[release]`、准备经确认的签名标准包及原文；安装器另需Inno Setup。私钥由维护者离线保管，不应提交到GitHub。参见安装发布说明及构建脚本。

## 验收边界

GB29446新建页面源码已PASS：12个等级边界、临界值、中文异常提示、正数输入、煤种工艺联动、只读k、核算周期、旧结果清除和保存均有测试。普通页面不含企业属性、单一煤种工艺确认及合规主结论。

753条正式指标扫描无缺项及边界偏差，不代表其他标准均完成现场业务验收；16项草案仍不可正式评价。新版EXE、安装包和公式Excel尚未同步完成最新口径验收。

历史文档盘符、数量与发布记录有日期背景。GB29446专用页面按用户最新要求显示“超出3级”，覆盖早期规范中的“未达标”措辞。

**等级判定口径（当前 / 历史）：**

- **当前口径**：等级比较使用 Decimal **full-value exact comparison**，不执行全局 ROUND6；企业属性填写与否不改变 GB 29446 指标等级。
- **历史口径（已废止）**：早期规范曾要求数值边界两侧先 `ROUND(value, 6)`（`ROUND_HALF_UP`）再比较；该无依据全局 ROUND6 已由 Numeric Contract v1 Full Adoption 移除，`D-ECQ-001` 已关闭。
- **当前权威来源**：`platform-lock.json`（locked SHA）、`docs/统一判定规范.md`、`docs/governance/NUMERIC_V1_ADOPTION_REPORT.md`。
