# 安装与发布说明

## 当前可直接使用的版本

当前同时交付两种 Windows x64 方式：

`UEBench-0.1.0-win-x64.zip`

`UEBench-Setup-0.1.0-x64.exe`

可选择直接运行 ZIP，或运行 Setup.exe 安装。两种方式都不需要安装 Python，也不需要网络连接。第一次启动会在 Windows 的本地应用数据目录创建 SQLite 数据库、日志、备份和标准包目录。

本版已处理 Qt/PySide6 的 ICU 依赖冲突：发布包不再携带开发机上 Poppler 的 `icuuc.dll`，避免出现“无法定位程序输入点 `ucnv_open` 于 Qt6Core.dll”。如果此前解压过旧版运行包，请删除旧的 `UEBench` 文件夹后重新解压本次包，不要混用新旧 `_internal` 文件。

## 校验文件

发布目录中的 `SHA256SUMS.txt` 与运行包放在同一目录。解压前先在 PowerShell 执行：

```powershell
Get-FileHash .\UEBench-0.1.0-win-x64.zip -Algorithm SHA256
```

只有输出值与 `SHA256SUMS.txt` 完全一致时才继续解压。

不懂编程时可在交付目录双击 `验收助手.cmd`。它会自动检查三个不可变文件的哈希、确认表和导入模板是否存在；如果检测到已解压目录中旧版 ICU DLL，也会明确提示删除旧目录，并生成验收结果文本；随后再按提示解压并双击 `UEBench\\UEBench.exe`。

## Inno Setup 安装程序

项目已提供 `packaging/installer.iss` 和 `scripts/build_release.ps1`。在安装 Inno Setup 6 的 Windows 构建机上执行：

```powershell
.\scripts\build_release.ps1
```

脚本会先运行测试、重建 PyInstaller 目录，再调用 `ISCC.exe` 生成 `dist/installer/UEBench-Setup-0.1.0-x64.exe`。本次 Setup.exe 已完成编译；在当前受管构建环境中静默安装会因 HKCU 卸载注册表写入被拒绝而回滚，便携版已完成隔离安装和启动烟测。请在普通 Windows 10/11 用户环境再验证 Setup 安装/卸载。

## 正式标准包发布

当前内置包为正式包，46 项、701 条规则状态为 `published`。确认表已由王玮于 2026-08-28 完成逐项确认。若后续标准修订，仍按以下命令生成新的版本：

```powershell
$env:PYTHONPATH = "src"
.\.venv\Scripts\python.exe tools\publish_confirmed_rules.py `
  "dist\release\统一标准规则确认表.xlsx" `
  "G:\标准  规范\02_能耗限额_终端产品\单位产品限额\现行强制文本" `
  --output "dist\standard-packages\initial-standard-package-published.uebench" `
  --apply
```

只有在新的确认表逐项完成人工确认后，才允许使用 `--apply`；当前交付目录中的正式包可用于首版验收。候选包仅供追溯，不用于正式判定。

## 65项范围草案的确认与发布

`work/next-scope-65` 是隔离工作区，不会被正式程序读取。完成其中 `65项标准规则确认表.xlsx` 的原文核对后，先用以下命令把已确认的 draft 提升为 `reviewed`，再执行上面的发布命令（两步均建议先不加 `--apply` 进行演练）：

```powershell
$env:PYTHONPATH = "src"
.\.venv\Scripts\python.exe tools\review_confirmed_rules.py `
  "work\next-scope-65\65项标准规则确认表.xlsx" `
  --data-dir "work\next-scope-65\data"
```

确认表未完成或存在缺失指标时，命令必须失败；不得手工修改 `publication_status` 绕过复核门槛。reviewed提升成功后，使用同一数据目录生成65项包：

```powershell
.\.venv\Scripts\python.exe tools\publish_confirmed_rules.py `
  "work\next-scope-65\65项标准规则确认表.xlsx" `
  "G:\标准  规范\02_能耗限额_终端产品\单位产品限额\现行强制文本" `
  --data-dir "work\next-scope-65\data" `
  --data-version "2026.08-published.2" `
  --output "dist\standard-packages\initial-standard-package-65-published.uebench" `
  --apply
```
