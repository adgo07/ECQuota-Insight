# UEBench 0.2.0 安装与发布说明

> 本文件是 **UEBench 0.2.0** 的安装与发布说明。
> 0.1.0 的对应说明已保留为历史材料，不作为本版本的普通用户文档。

## 1. 本版本是什么

- 产品版本：**0.2.0**（唯一版本源：`pyproject.toml` `[project] version`）
- 平台：Windows 10 / 11 x64
- 性质：**未发布版本说明**；本轮候选必须从 RS05 最终干净源码 Head 构建并通过交付门禁；**尚未授权正式发布**
- Reference Standard：`GB 29446—2019《选煤电力消耗限额》`
- 配套标准库版本：2026.10-published.4（48 项标准 / 765 条规则；标准原文 PDF 不随软件分发，用户无需单独安装标准库）

0.2.0 相对 0.1.0 的主要变化：

- GB 29446 业务闭环（RS01）、产品生命周期闭环（RS02）、Excel Adapter 技术能力（RS03）、
  Product Golden v1（RS04）；Excel 正式用户工作流暂缓开放；
- 构建 / 自检所需的 GB 29446 模板由软件**无头确定性生成**；Excel 正式用户工作流暂缓开放；
- 版本管理改为**单一版本源**，正式发布链不再手工同步版本号；
- 数据库 schema 升级前**自动建立安全备份**；
- 覆盖安装会先清理旧应用载荷，避免旧 `_internal` 残留；
- 单条损坏的历史记录不再影响“评价记录”与首页加载。

## 2. 代码签名状态（重要）

**本版本未进行 Authenticode 代码签名。**

```text
authenticode_signed = false
unsigned_reason     = no_signing_certificate
```

因此：

- Windows 可能显示“未知发布者”，SmartScreen 可能给出警告；
- 企业环境的应用程序控制 / 白名单策略**可能阻止**未签名程序运行；
- 安装前请用 `SHA256SUMS.txt` 核对文件哈希（见 §3）。

> 配套标准库由完整软件自动使用并校验完整性；普通用户无需单独安装标准包。内部内容签名与 Windows Authenticode 代码签名是两件不同的事。

## 3. 交付物与校验

> **关于文件名中的 `-rc-<short7>`**：Release Candidate 阶段的三个应用产物名里带

> 这样两个内容不同的 Candidate 不会都叫 `UEBench-0.2.0-win-x64.zip`，
> 人工测试时可直接从文件名反查精确源码。正式发布（formal release cut）时才去掉该后缀。
> 用哪个名字请看该交付目录里的 `release-build-info.json`（`candidate_id` 字段）。
> 下表同时给出两种形态。

| 文件 | Release Candidate 阶段 | 正式发布 |
|---|---|---|
| 便携版，解压即用 | `UEBench-0.2.0-rc-<short7>-win-x64.zip` | `UEBench-0.2.0-win-x64.zip` |
| 安装程序 | `UEBench-Setup-0.2.0-rc-<short7>-x64.exe` | `UEBench-Setup-0.2.0-x64.exe` |

以下文件随交付目录提供，属于**内部校验与归档辅助产物**（不是普通用户需要单独管理或下载的资产）：

## 4. 安装

### 4.1 便携版（推荐用于快速试用）

解压便携包（`UEBench-0.2.0-rc-<short7>-win-x64.zip`，正式发布时为 `UEBench-0.2.0-win-x64.zip`），双击 `UEBench\UEBench.exe`。

> 请**不要**把新版本解压覆盖到旧版本的 `UEBench` 文件夹上。若此前解压过旧版，
> 请先删除整个旧 `UEBench` 文件夹再解压，避免新旧 `_internal` 混用。

### 4.2 安装程序

运行安装程序（`UEBench-Setup-0.2.0-rc-<short7>-x64.exe`，正式发布时为 `UEBench-Setup-0.2.0-x64.exe`）。默认安装到 `%ProgramFiles%\UEBench`
（非管理员账户可安装到用户目录）。安装向导为简体中文。

## 5. 升级（0.1.0 → 0.2.0）

0.2.0 是**唯一承诺**支持从上一正式版升级的版本。

1. 直接运行 0.2.0 安装程序覆盖安装即可；
2. 安装程序会先**清理旧的应用载荷**（`_internal`、`UEBench.exe`、`文档`、`模板`），
   再安装新载荷，因此不会残留旧版 DLL 或旧的数据库迁移脚本；
3. **用户数据不会被删除**（见 §6）；
4. 首次以 0.2.0 启动时，如果数据库 schema 需要升级，软件会**自动先建立
   升级前备份**，再执行迁移。

升级前备份位置：`%LOCALAPPDATA%\UEBench\backups\pre-migration-<时间戳>.uebackup`

- 迁移**失败**时：原数据库与备份都保留；
- 迁移**成功**时：备份同样保留（不会自动删除）；
- schema 已经是最新时：**不会**每次启动重复备份。

## 6. 用户数据、卸载与恢复

用户数据目录：`%LOCALAPPDATA%\UEBench\`

```text
uebench.sqlite3          业务数据库
uebench.sqlite3-wal      SQLite WAL
uebench.sqlite3-shm      SQLite 共享内存
standards\               已安装标准定义（不再保存标准原文 PDF）
backups\                 备份（含升级前备份）
logs\                    运行日志
imports\                 导入批次
```

- **卸载**会删除程序文件；
- **卸载默认保留**上述用户数据库、备份与业务文件；
- 重新安装后，原有评价记录仍在。

验证流程：安装 → 建立记录 → 卸载 → 数据仍在 → 重新安装 → 记录恢复。

## 7. 标准库与 GB 29446

- 标准库随完整软件版本配套更新；首次安装会自动安装内置标准库，版本完全匹配时不会重复安装或备份，旧版本按现有安全机制自动升级；
- 内置包的签名、哈希、版本身份与升级安全检查由软件自动完成，不要求普通用户选择、导入或维护标准包；
- 若标准库比软件内置版本更新、同版本内容冲突或无法确认配套关系，软件不会降级或覆盖，并会暂停新正式评价。界面提示：“当前标准库与软件版本不匹配，暂时不能新建评价。请安装完整的新版本。历史记录和备份仍可继续使用。”
- 若软件内置标准库资源缺失或完整性检查失败，软件不会假装安装成功，也不会允许新正式评价；用户应重新安装完整软件，现有数据与历史记录继续保留；
- 安全升级或恢复后，旧评价仍按保存时的结果和规则快照查看，不会按新规则重算；恢复备份后软件会先对账，再刷新普通页面并开放新评价；
- GB 29446—2019 的等级判定使用 full-value exact Decimal 比较，不执行隐式六位小数修约（依据 ECQ-STD-GB29446-001，状态仍为 PROVISIONAL）；
- 若当前加载的 GB 29446 定义缺少正式 r2 所需结构（煤种维度或工艺系数查表行），软件会明确提示规则数据不完整或版本不兼容，并禁止正式计算；
- Excel Adapter technical capability = RETAINED；Excel user-facing formal workflow = DEFERRED。技术模板、应用接口与测试保留，但普通用户界面不开放 Excel 正式导入/评价。
- 技术诊断仅在“设置 → 高级”中查看或复制，可包含软件版本、标准库完整身份、校验结果、数据库 schema、源码提交与最近一次标准库对账信息；普通页面只显示标准库版本。

### 7.1 验收边界

1. Windows 实机验收证据仍需按 RS05 执行报告中的实际结果记录；未实测的平台、显示器组合或 DPI 档位不得报告为通过。
2. 恢复的标准库若比软件内置版本更新，软件会保留该库并暂停新正式评价，不会自动降级；安装配套完整软件后由软件执行对账。历史评价和备份仍可使用。


## 8. Reference Standard Product Closure

Reference Standard Product Closure = PARTIAL
RS05 = IN PROGRESS
RS06 = NOT STARTED

RS05 当前目标为 Product Simplification & Standard Library Pairing。交付候选必须由该阶段完成后的精确源码 Head 重新构建并通过门禁；不得据此宣布 RS05 完成或正式发布 0.2.0。

### 0.2.0 正式评价范围与标准原文（Phase 7 收口）

- 0.2.0 的**正式评价范围只有 GB 29446—2019《选煤电力消耗限额》**。其他标准可以继续出现在
  标准库中作为目录/参考信息，但**不得**作为正式评价对象，界面显示「尚未纳入正式评价范围」。
  “标准库里有该标准”不等于“软件已正式支持评价”。
- 0.2.0 **不随软件分发、也不在软件数据目录保存标准原文 PDF**；普通界面提供
  「查看标准原文」，点击后打开**全国标准信息公共服务平台**上预先登记的官方页面
  （不进行运行时搜索或抓取）。未登记官方地址的标准，该入口禁用并提示
  「官方来源地址尚未登记」。
- 标准定义中仍保留标准编号、原文文件名与 SHA-256 等**追溯元数据**，但不再分发原文文件本身。
- 评价记录的时间按**操作系统本地时区**显示，精确到秒（数据库仍以 UTC 存储）。
