# 统一判定规范

状态：用户已确认。所有标准后续完善均须遵循。GB 29446—2019 的 Phase 0 闭环在独立分支实施；只有本文对应的验收记录和实际构建证据更新后，方可称源码、Excel或发布物通过。

## 1. 所有数值边界比较先修约六位小数

比较两侧均先执行 ROUND(数值,6)，再执行 <=、<、>=、>、= 或 !=。包括等级限额、限定值、适用条件、区间、分段公式和查表数值边界。文本、枚举匹配不适用数值修约。

软件使用Decimal和ROUND_HALF_UP，与Excel ROUND一致；不得使用二进制浮点进行标准边界比较。中间运算保持原精度，在比较前修约。显示位数不改变判定，轨迹保留原始值和比较值。

例如8.5000004修约为8.500000，8.5000005修约为8.500001。

## 2. 最低要求未满足输出未达标

指标未满足标准自身最低要求（通常为三级或限定值）时，统一输出“未达标”，不得用“超出3级”等替代。原文比较方向、缺级和适用范围如实保留，不猜测补值。计算必需数据缺失仍为“不完整”，确实不适用仍为“不适用”。

## 3. 标准适用条件不得冒充等级

按标准原文定义的产品、工艺和其他适用条件选择规则。需要说明行政准入或企业要求时，只有原文明确要求且产品界面已获确认，才能作为与能耗等级分开的说明；不得把它变成隐藏输入、判级前提或替代等级的结论。

GB 29446—2019 的正式输入只有煤种、选煤工艺、统计期电力消耗量 E_d 和入选原煤量 m。企业建设属性和单一煤种确认不属于该评价输入；软件仅按工艺系数 k 和能耗限额判级。

## 4. 验收要求

每个标准的引擎、界面、保存读取、导出和公式Excel都遵循其已确认的正式输入契约。测试须覆盖六位修约临界值（第七位4和5）、标准适用的比较方向、最低要求不满足显示未达标，以及必需计算数据缺失。GB 29446 使用 E_d、m 和规则自动匹配的 k 验证公式与所有等级边界，不以旧直接单耗入口或企业属性作为测试前提。软件与 Excel 结果须一致。历史评价不自动重算，保留当时口径和原始证据。
