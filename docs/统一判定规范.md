# 统一判定规范

状态：用户已确认。所有标准后续完善均须遵循；现有软件和Excel尚待整改，本轮仅记录规范。

## 1. 所有数值边界比较先修约六位小数

比较两侧均先执行 ROUND(数值,6)，再执行 <=、<、>=、>、= 或 !=。包括等级限额、限定值、适用条件、区间、分段公式和查表数值边界。文本、枚举匹配不适用数值修约。

软件使用Decimal和ROUND_HALF_UP，与Excel ROUND一致；不得使用二进制浮点进行标准边界比较。中间运算保持原精度，在比较前修约。显示位数不改变判定，轨迹保留原始值和比较值。

例如8.5000004修约为8.500000，8.5000005修约为8.500001。

## 2. 最低要求未满足输出未达标

指标未满足标准自身最低要求（通常为三级或限定值）时，统一输出“未达标”，不得用“超出3级”等替代。原文比较方向、缺级和适用范围如实保留，不猜测补值。计算必需数据缺失仍为“不完整”，确实不适用仍为“不适用”。

## 3. 企业属性不影响指标判级

企业属性为可选信息。未填写或填写现有、新建、改扩建等属性，均按同一指标规则正常输出一级、二级、三级或未达标等结论。即使不符合新建或改扩建准入要求，也不得阻止计算、改变等级、将三级改成未达标或将结果变成不完整。

例如GB 29446—2019炼焦煤电力单耗8.0 kW·h/t，属性留空、现有、新建、改扩建均判三级；超过该指标三级限额时才判未达标。

原文企业限定及准入要求可保留为说明。独立提示须与指标结论分开，不能作为必填项、判级前提或指标最终结论。

## 4. 验收要求

所有标准、直接录入和明细计算、引擎、界面、保存读取、导出和公式Excel均遵循本规范。测试须覆盖六位修约临界值（第七位4和5）、全部比较方向、企业属性四种情况结论一致、最低要求不满足显示未达标，以及必需计算数据缺失。软件与Excel结果须一致。历史评价不自动重算，保留当时口径和原始证据。
