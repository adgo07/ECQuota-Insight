## 2. 适用范围

### 2.1 标准规定内容

本标准规定了煤炭行业煤炭洗选过程选煤电力单耗限额的技术要求、统计范围和计算方法。

### 2.2 适用对象

本标准适用于煤炭行业煤炭洗选过程：

1. 选煤电力单耗的计算；
2. 选煤电力单耗的考核；
3. 新建企业的电力单耗控制；
4. 改扩建企业的电力单耗控制。

**出处：**S1，PDF第3页，标准第1章。上述分项为对原文并列内容的整理。

**解释说明：**某一具体工艺在附录A中没有对应系数，不自动等于标准明文规定该企业不适用；应分别说明标准适用范围、具体取值是否明确及软件能否完成评价。

## 5. 电力单耗等级映射

**标准事实：**标准表1、表2均列出1级、2级、3级的单耗上限，并说明“1级能耗最低”。

**解释说明：**下表“标准上限”直接来自原文；“互斥判定区间”由标准上限及等级关系整理，用于输出单一等级。判定时依次匹配满足条件的最高等级，即等级数字最小者。互斥区间和伪代码是对标准要求的实现性表达，不是原表逐字列示的内容。

以下判级以能够按本表第8节取得有效计算值为前提。

### 5.1 炼焦煤选煤企业

| 标准等级 | 标准上限（kW·h/t） | 互斥判定区间（由上限整理） |
|---|---|---|
| 1级 | ≤5.0 | $e_d \le 5.0$ |
| 2级 | ≤7.0 | $5.0 < e_d \le 7.0$ |
| 3级 | ≤8.5 | $7.0 < e_d \le 8.5$ |

**出处：**S1，PDF第3页，标准第3.1条、表1。

**软件判定表达：**

```text
前提：选煤企业类型为炼焦煤，且已取得有效的选煤电力单耗 e_d。

IF e_d <= 5.0:
    评价结果 = 1级
ELSE IF e_d <= 7.0:
    评价结果 = 2级
ELSE IF e_d <= 8.5:
    评价结果 = 3级
ELSE:
    评价结果 = 未达3级
```

### 5.2 动力煤选煤企业

| 标准等级 | 标准上限（kW·h/t） | 互斥判定区间（由上限整理） |
|---|---|---|
| 1级 | ≤2.0 | $e_d \le 2.0$ |
| 2级 | ≤3.0 | $2.0 < e_d \le 3.0$ |
| 3级 | ≤4.5 | $3.0 < e_d \le 4.5$ |

**出处：**S1，PDF第3页，标准第3.2条、表2。

**软件判定表达：**

```text
前提：选煤企业类型为动力煤，且已取得有效的选煤电力单耗 e_d。

IF e_d <= 2.0:
    评价结果 = 1级
ELSE IF e_d <= 3.0:
    评价结果 = 2级
ELSE IF e_d <= 4.5:
    评价结果 = 3级
ELSE:
    评价结果 = 未达3级
```

### 5.3 “未达3级”与“无法判定”

| 软件结果标签 | 使用条件 | 性质 |
|---|---|---|
| 未达3级 | 炼焦煤的有效计算值 $e_d>8.5$，或动力煤的有效计算值 $e_d>4.5$ | 用户本次确认的软件结果标签，表示未达到相应3级限值；不是标准术语或第四个等级 |
| 无法判定 | 数据缺失、分母为0、输入异常、工艺无法取得对应系数，或其他原因导致不能形成有效判断 | 软件异常状态说明建议；应附具体原因，不等同于单耗超过限值 |

**已确认决定：**按S3，“超出3级”这一原软件标签统一改为“未达3级”（D01，见本表第13.4节）。等于8.5的炼焦煤单耗、等于4.5的动力煤单耗仍满足各自3级限值；本次命名不改变比较方向和任何边界。

## 8. 选煤电力单耗计算

### 8.1 标准公式

$$
e_d=\frac{E_d\times k}{m}
$$

即：`e_d = E_d × k / m`。

| 符号 | 标准含义 | 单位 | 取值说明 |
|---|---|---|---|
| $e_d$ | 选煤电力单耗 | kW·h/t | 按式（1）计算 |
| $E_d$ | 统计期内选煤电力消耗量 | kW·h | 企业统计数据，统计范围依据标准第5.1条 |
| $k$ | 选煤工艺类型折算系数 | — | 按标准附录A选取 |
| $m$ | 统计期内入选原煤量 | t | 企业统计数据 |

**出处：**S1，PDF第4页，标准第5.2条、式（1）。

### 8.2 计算关系与数据对应

**解释说明：**按标准定义及变量含义，$E_d$ 与 $m$ 应对应同一统计期和相应评价范围。未折算的 $E_d/m$ 可以作为辅助展示值；正式选煤电力单耗是按标准式（1）乘以 $k$ 后的结果。

对能够直接对应标准表A.1某一行的情形：

1. 确定选煤企业类型与选煤工艺类型。
2. 按该组合选取 $k$。
3. 取得对应统计期的 $E_d$ 与 $m$。
4. 按式（1）计算 $e_d$，再依据标准表1或表2判级。

### 8.3 计算有效条件与异常输入

本节区分数学有效性和软件处理建议，不把软件数据校验措辞当作标准新增条款。

| 情形 | 性质 | 计算或处理说明 |
|---|---|---|
| $m=0$ | 数学上无法按式（1）计算 | 分母为0，不进入等级比较 |
| 电量或原煤量缺失、不是有效有限数值 | 无法形成有效输入；具体提示属于软件设计 | 建议输出“无法判定”及原因，不以0替代缺失值 |
| $m<0$ 或 $E_d<0$ | 与本表所用数量含义不符；具体拦截属于软件设计 | 建议作为输入异常处理，不据负单耗给出等级 |
| 企业类型或工艺无法对应表A.1 | 标准取值或资料不足 | 说明不能取得对应系数；不自行选相近值、平均值或默认1 |
| $E_d=0$ 且 $m>0$ | 标准未禁止；数学上可按式（1）算出 $e_d=0$ | 软件按 D02 将其作为待核实输入拦截并说明原因；该拦截是软件防误录规则，**不得表述为标准要求** |

| 3 | 统计期内选煤电力消耗量 $E_d$ | 数值输入，kW·h |
| 4 | 统计期内入选原煤量 $m$ | 数值输入，t |

这4项是公式取值和等级判断的核心输入，不表示评价记录只需要这4个字段。还应注明共同的统计期，并说明输入数据的评价范围；标准没有限定统计期必须为年度。

系统据此取得或计算：

- 选煤工艺类型折算系数 $k$；
- 选煤电力单耗 $e_d$；
- 1级、2级、3级，或已确认的软件结果“未达3级”；不能形成有效判断时说明状态与原因。
