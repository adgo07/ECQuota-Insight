# GB 29446—2019 选煤标准映射入口

程序标准 ID：`gb-29446-2019`。**现行批准的独立完整映射文档：无；建议补建。** 本页是现有证据导航和缺口清单，不是标准映射表，不包含新增业务规则。

## 为什么需要补建

现有规则JSON记录软件可执行字段、公式、参数和限值，Golden记录案例、来源和独立推导；两者各有职责，但未集中呈现标准适用范围、统计边界、全部字段及条件、异常与不适用场景、标准事实和软件决定的对应关系。

选煤是当前参考标准。补建可形成后续几十个标准能够复用的完整样例，也便于检查“条款→映射→规则→测试”的覆盖情况。**缺少完整映射不等于现有计算错误，也不撤销已完成的业务与验证证据。**

## 补建范围与完成条件

建议后续在本目录按 [模板](../templates/标准映射表模板.md) 新建 `标准映射表_V1.0_草稿.md`，再独立核对：

1. 核验原始标准来源、SHA256、条款/表/公式定位；本次目录整理没有重新审核标准PDF，不把既有报告的核对记录当作本次核对。
2. 整理适用/不适用范围、统计边界、煤种与工艺、输入及条件、自动查表参数、公式、限额、判定、异常及输出。
3. 逐项区分原文事实、技术解释、已确认软件决定和实际实现；引用已有规则与测试，不把代码反向当作权威原文。
4. 为关键映射项给出稳定编号，并链接对应规则、测试和Golden；缺项标“待核”，发现影响结果的差异先登记和说明影响，再另行决定修复。
5. 复用现有Numeric治理、产品证据与支持范围，避免借补表重新设计算法或推进RS06。
6. 审核及批准证据齐备后，同步更新本入口和总索引；此前不标已批准、不标MAPPING FROZEN，也不因文档补齐宣布产品验收完成。

本轮完成目录入口与必要性评估，完整映射正文尚未编制。
