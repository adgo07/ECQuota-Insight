## 采用边界

- D01：有效单耗超过对应 3 级上限时，软件结果名为“未达3级”。它不是第四等级，也不代替无法判定；旧界面中的“超出3级”是待同步的历史表述。
- D02：仅本标准的软件防误录校验要求统计期内选煤电力消耗量 $E_d>0$、入选原煤量 $m>0$；不冒充标准明文，也不推广到其他标准。
- 当前正式评价范围仍只有 GB 29446—2019；普通页面不恢复企业建设属性、限定值/准入值符合性主结论。映射完整记录标准第 4 章，不等于当前产品启用该可选判断。
- UI 与 Word 采用批准映射的字段、单位、选项、说明和结果含义；未来 Excel 如启动，也使用同一业务描述和计算链。特殊命名须有 Owner 明确特批及采用记录。渠道间允许布局、分页和展开方式不同。
- 已有选煤数值 Golden 和定向回归保留为独立数值证据，但仍须核对新映射身份、D01/D02 和展示内容；已有 JSON、Golden、旧发布物不能取代本版映射或证明新的多渠道验收已完成。
