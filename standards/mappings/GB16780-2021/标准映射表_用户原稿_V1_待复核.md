# 4. 能耗限额等级映射

标准规定**1级能耗最低，2级次之，3级最高**。 01.GB 16780-2021水泥单位产品能源消耗限额

## 4.1 水泥单位产品综合能耗

### 表1 水泥单位产品综合能耗限额等级

|指标|单位|1级|2级|3级|
|---|---|---|---|---|
|水泥单位产品综合能耗 `E_s`|kgce/t|≤80|≤87|≤94|

### 判级逻辑

```
E_s ≤ 80
→ 1级

80 < E_s ≤ 87
→ 2级

87 < E_s ≤ 94
→ 3级

E_s > 94
→ 未达到3级
```

01.GB 16780-2021水泥单位产品能源消耗限额

---

## 4.2 熟料单位产品能耗

### 表2 熟料单位产品综合能耗、综合电耗与综合煤耗限额等级

|指标|单位|1级|2级|3级|
|---|---|---|---|---|
|熟料单位产品综合能耗 `E_sh`|kgce/t|≤100|≤107|≤117|
|熟料单位产品综合电耗 `W_sh`|kW·h/t|≤48|≤57|≤61|
|熟料单位产品综合煤耗 `e_sh`|kgce/t|≤94|≤100|≤109|

标准将三个指标并列规定，并分别设置1级、2级、3级限额。 01.GB 16780-2021水泥单位产品能源消耗限额

### 判定原则

三个指标**分别判级，分别输出评价结论**，不合成为一个所谓“熟料最终等级”。

例如：

|指标|实际值|判定结果|
|---|---|---|
|熟料单位产品综合能耗|103 kgce/t|2级|
|熟料单位产品综合电耗|46 kW·h/t|1级|
|熟料单位产品综合煤耗|105 kgce/t|3级|

软件输出应保持：

```
熟料单位产品综合能耗：2级
熟料单位产品综合电耗：1级
熟料单位产品综合煤耗：3级
```

**不再输出：**

```
熟料最终等级：3级
```

> 标准表2虽然同时列出了三项熟料能耗指标，但没有规定将三项判级结果进一步合成为一个“熟料综合等级”，因此软件不自行增加这一评价概念。

# 7. 海拔修正

## 7.1 适用条件

标准5.3的适用对象为：

> **生产水泥和水泥熟料产品的现有企业**，且厂区位置海拔高度大于1500 m。

在满足上述条件时，对相关指标的**3级限额值**进行海拔修正。 01.GB 16780-2021水泥单位产品能源消耗限额 01.GB 16780-2021水泥单位产品能源消耗限额

软件条件建议明确写为：

```
企业属性 = 现有企业
AND
企业生产水泥
AND
企业生产水泥熟料
AND
厂区海拔高度 > 1500 m
```

不能仅按：

```
现有企业 AND 海拔 > 1500 m
```

自动触发。

---

## 7.2 海拔修正系数

\[ K=1.179-0.211\times\frac{P_H}{P_0} \]

其中：

|参数|含义|单位|
|---|---|---|
|`K`|海拔修正系数|—|
|`P_0`|海平面环境大气压，取101325|Pa|
|`P_H`|水泥窑所在地环境大气压|Pa|

标准5.3规定的修正对象为以下**3级限额值**：

|指标|基准3级限额|
|---|---|
|水泥单位产品综合能耗|94 kgce/t|
|熟料单位产品综合能耗|117 kgce/t|
|熟料单位产品综合电耗|61 kW·h/t|
|熟料单位产品综合煤耗|109 kgce/t|

因此单独发生海拔修正时：

\[ L'_{3}=L_{3}\times K \]

# 8. 水泥熟料比例修正

当水泥产品中熟料配比高于或低于75%时，水泥单位产品综合能耗限额值进行修正。

每变化1个百分点：

|等级|修正量|
|---|---|
|1级|1.10 kgce/t|
|2级|1.15 kgce/t|
|3级|1.20 kgce/t|

01.GB 16780-2021水泥单位产品能源消耗限额

令：

```
g = 水泥中熟料平均配比，%
Δg = g - 75
```

则：

\[ L_1=80+1.10(g-75) \]\[ L_2=87+1.15(g-75) \]

当不存在海拔修正时：

\[ L_3=94+1.20(g-75) \]

---

# 8.1 海拔修正与熟料比例修正同时发生

标准5.3规定海拔修正，5.4规定熟料比例修正，但**没有明确规定两项修正同时发生时的组合公式或计算顺序**。 01.GB 16780-2021水泥单位产品能源消耗限额

本软件采用以下处理规则：

> **先对表1中的3级基准限额值进行海拔系数修正，再加熟料比例修正量。**

即：

\[ \boxed{ L_{3,\ corrected} = 94\times K + 1.20\times(g-75) } \]

其中：

- `94`：表1水泥单位产品综合能耗3级基准限额；
- `K`：海拔修正系数；
- `g`：水泥中熟料平均配比，单位 `%`。

例如：

```
K = 1.05
熟料比例 g = 80%

海拔修正：
94 × 1.05 = 98.70

熟料比例修正：
(80 - 75) × 1.20 = 6.00

最终3级限额：
98.70 + 6.00 = 104.70 kgce/t
```

### 软件性质说明

这一组合规则应在程序和映射表中标记为：

```
软件实现约定
```

而不能写成：

```
GB 16780—2021规定
```

因为标准原文没有明确给出两种修正同时发生时的运算顺序。

### 1级和2级

由于标准5.3只规定对**3级限额**进行海拔修正：

\[ L_1=80+1.10(g-75) \]\[ L_2=87+1.15(g-75) \]\[ L_3=94K+1.20(g-75) \]

因此这三式可以直接作为软件的水泥综合能耗动态限额生成规则。

## 8.2 每变化1个百分点的修正量

|等级|每增减1%熟料比例的限额修正量|
|---|---|
|1级|1.10 kgce/t|
|2级|1.15 kgce/t|
|3级|1.20 kgce/t|

标准原文规定见第5.4。 01.GB 16780-2021水泥单位产品能源消耗限额

## 8.3 软件公式映射

设：

```
g = 水泥熟料比例，%
Δg = g - 75
```

则：

### 1级

\[ L_1=80+1.10\times(g-75) \]

### 2级

\[ L_2=87+1.15\times(g-75) \]

### 3级

\[ L_3=94+1.20\times(g-75) \]

例如：

```
熟料比例 = 80%
Δg = +5

1级限额 = 80 + 5×1.10 = 85.50
2级限额 = 87 + 5×1.15 = 92.75
3级限额 = 94 + 5×1.20 = 100.00
```

如果熟料比例为70%：

```
Δg = -5

1级限额 = 74.50
2级限额 = 81.25
3级限额 = 88.00
```

# 9. 协同处置和替代燃料

标准5.5规定，当企业存在协同处置或使用替代燃料时，在相关能耗等级限额评价中应扣除协同处置消耗的能源量和替代燃料量。 01.GB 16780-2021水泥单位产品能源消耗限额

但该条：

- 没有给出统一计算公式；
- 没有给出统一折算方法；
- 没有规定各种协同处置场景的具体扣除边界；
- 没有像海拔修正和熟料比例修正一样给出明确数值算法。

因此软件**不得自行生成统一扣除算法**。

## 软件处理原则

软件只提供相关数据录入和扣除接口，例如：

|字段|类型|
|---|---|
|是否存在协同处置|是/否|
|是否使用替代燃料|是/否|
|协同处置消耗能源量|数值/明细|
|替代燃料量|数值/明细|
|扣除量|数值|
|扣除依据/说明|文本|
|数据来源|文本|

具体扣除口径由：

```
企业
/
审核机构
/
相关主管部门
/
标准解释文件
```

确定。

软件应允许形成类似提示：

> 本企业存在协同处置或替代燃料。GB 16780—2021第5.5条要求扣除相关能源量和替代燃料量，但标准未规定统一扣除算法，请依据实际生产情况及审核口径确认扣除数据。

## 计算层强制转换

计算时必须统一转换：

\[ g_{calc}=\frac{g_{input}}{100} \]

例如：

```
用户输入：

g = 75

计算层：

g_calc = 75 / 100
       = 0.75
```

因此软件实际计算逻辑应为：

\[ E_s = e_{sh}\times\frac{g}{100} + \frac{e_h}{P_s} + 0.1229W_s \]

### 强制规则

该转换必须：

```
在计算内核自动完成
```

不得：

```
要求用户自行把75%换成0.75
```

也不得让不同页面或不同导入方式采用不同口径。

建议固化为统一数据契约：

```
界面/Excel/API输入：
g = 75

Canonical业务值：
g = 75 %

计算内部值：
g_ratio = Decimal("0.75")
```

这样 GUI 手工录入、Excel 导入和后续批量计算的含义始终一致。

# 17. 外购熟料对水泥单位产品综合能耗的处理

## 17.1 全部采用外购熟料

当企业全部采用外购熟料生产水泥时，式（8）中的 `e_sh` 按0计算。

即：

e_sh = 0

因此水泥单位产品综合能耗计算为：

E_s = e_h / P_s + 0.1229 × W_s
## 17.2 外购部分熟料

### 水泥综合电耗

对于部分外购熟料企业，式（7）中的：

```
W_sh
```

采用本企业：

```
熟料单位产品综合电耗
```

这一处理与变量定义一致。 01.GB 16780-2021水泥单位产品能源消耗限额

### 水泥综合能耗

标准6.2.5后文写明，部分外购熟料时，式（8）中的 `e_sh` 应采用本企业熟料单位产品“综合能耗”数据。 01.GB 16780-2021水泥单位产品能源消耗限额

但这里存在明显的变量名称与文字说明不一致：

在6.2.1中：

```
e_sh
```

明确被定义为：

> 熟料单位产品综合煤耗

其单位为：

```
kgce/t
```

而熟料单位产品综合能耗使用的变量为：

```
E_sh
```

且6.2.3明确规定：

\[ E_{sh}=e_{sh}+0.1229W_{sh} \]

即 `E_sh` 与 `e_sh` 是两个不同指标。 01.GB 16780-2021水泥单位产品能源消耗限额

因此，本映射采用以下解释：

> **6.2.5中“e_sh采用本企业熟料单位产品综合能耗数据”中的“综合能耗”疑为文字笔误。按照公式变量定义及式（8）的量纲和计算逻辑，`e_sh` 应采用本企业熟料单位产品综合煤耗数据。**

### 软件实现规则

```
部分外购熟料：

式（8）中的 e_sh
=
本企业熟料单位产品综合煤耗
```

不能使用：

```
本企业熟料单位产品综合能耗 E_sh
```

### 映射状态

建议在规则文件中增加：

```
source_status: suspected_standard_typo
implementation_basis: variable_definition_and_formula_consistency
```

或者中文表述：

```
标准疑似笔误：
标准正文写“综合能耗”，
软件依据变量定义、公式关系及量纲一致性，
按“综合煤耗”执行。
```

这样以后标准发布勘误或官方解释时，可以快速定位和修改。

# 17.3 粉磨站适用边界

外购熟料粉磨站本身不生产熟料，因此不能机械套用完整的熟料评价体系。

标准第5.1和5.2分别对外购熟料生产水泥的粉磨站作了专门规定：

- 现有粉磨站：水泥制备工段电耗应满足表3的3级要求；
- 新建、改建、扩建粉磨站：水泥制备工段电耗应满足表3的2级要求。 01.GB 16780-2021水泥单位产品能源消耗限额

因此建议区分如下。

|指标|自产熟料水泥企业|外购熟料粉磨站|
|---|---|---|
|水泥单位产品综合能耗|适用|不作为5.1/5.2粉磨站准入/限定评价指标|
|熟料单位产品综合能耗|适用|不适用|
|熟料单位产品综合煤耗|适用|不适用|
|熟料单位产品综合电耗|适用|不适用|
|水泥制备工段电耗|适用|**适用，核心评价指标**|

### 海拔修正

5.3的表述针对：

> 生产水泥和水泥熟料产品的现有企业。

因此单纯外购熟料的粉磨站：

```
不生产熟料
```

不满足5.3规定的对象条件。

所以：

```
外购熟料粉磨站
→ 不启用5.3海拔修正
```

即不能因为：

```
海拔 > 1500 m
```

就自动修正水泥单位产品综合能耗3级限额。

# 26. 实现时需要特别注意的两个问题

## 26.1 熟料比例 `g` 的百分数问题

标准式（8）写为：

\[ E_s=e_{sh}\times g+\frac{e_h}{P_s}+0.1229W_s \]

同时定义：

```
g——统计期内水泥企业水泥中熟料平均配比，%
```

因此软件界面如果输入：

```
75%
```

实际计算必须使用：

```
0.75
```

建议把这个转换固化在计算层，不让用户自己转换。

---

## 26.2 海拔修正与熟料比例修正同时发生

GB 16780—2021第5.3和5.4分别规定海拔修正和熟料比例修正，
但没有规定两项修正同时发生时的组合顺序。

本软件采用以下实现约定：

L3 = 94 × K + 1.20 × (g - 75)

即：
1. 表1水泥单位产品综合能耗3级基准值94先乘海拔修正系数K；
2. 再加熟料比例修正量。

该规则属于软件实现约定，不作为GB 16780—2021标准明文要求。

## 27. 标准判定核心结构

最终可以把本标准抽象成四类评价对象：

|评价对象|核心指标|等级|
|---|---|---|
|水泥|水泥单位产品综合能耗|1/2/3级|
|熟料|综合能耗 + 综合煤耗 + 综合电耗|1/2/3级|
|水泥制备工段|工段电耗|1/2/3级|
|项目准入/现有企业限定|上述指标对应等级|现有≥3级；新改扩≥2级|

这部分是整个 **GB 16780—2021 软件化映射的主骨架**。标准的限额等级原值见表1～表3。 01.GB 16780-2021水泥单位产品能源消耗限额

我建议后续开发时，**不要把 GB 16780—2021 做成一个简单的“输入一个能耗值→查表判级”标准**。它实际上属于较复杂型标准：有多指标、企业属性、外购熟料、海拔修正、熟料比例修正、余热发电扣减、协同处置以及多生产线分摊。最适合把它归入你前面确定的“复杂型新建评价”框架。
