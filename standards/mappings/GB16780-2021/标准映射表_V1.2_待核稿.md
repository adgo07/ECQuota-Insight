## 4.2 熟料单位产品能耗

### 表2 熟料单位产品综合能耗、综合电耗与综合煤耗限额等级

|指标|单位|1级|2级|3级|
|---|---|---|---|---|
|熟料单位产品综合能耗 `E_sh`|kgce/t|≤100|≤107|≤117|
|熟料单位产品综合电耗 `W_sh`|kW·h/t|≤48|≤57|≤61|
|熟料单位产品综合煤耗 `e_sh`|kgce/t|≤94|≤100|≤109|

标准将三个指标并列规定，并分别设置1级、2级、3级限额。 01.GB 16780-2021水泥单位产品能源消耗限额

### 判定原则

三个指标**分别判级，分别输出评价结论**，不合成为一个所谓“熟料最终等级”。

例如：

|指标|实际值|判定结果|
|---|---|---|
|熟料单位产品综合能耗|103 kgce/t|2级|
|熟料单位产品综合电耗|46 kW·h/t|1级|
|熟料单位产品综合煤耗|105 kgce/t|3级|

软件输出应保持：

```
熟料单位产品综合能耗：2级
熟料单位产品综合电耗：1级
熟料单位产品综合煤耗：3级
```

**不再输出：**

```
熟料最终等级：3级
```

> 标准表2虽然同时列出了三项熟料能耗指标，但没有规定将三项判级结果进一步合成为一个“熟料综合等级”，因此软件不自行增加这一评价概念。

# 7. 海拔修正

## 7.1 标准原文与软件适用范围分别记录

**标准原文事实（§5.3）**：海拔修正明确描述为“生产水泥和水泥熟料产品的现有企业”、位置海拔严格大于1500m时，表1及表2相关四项**3级限额值**乘以修正系数K；标准并未规定所有企业类型普遍适用。

**用户已确认的软件扩展口径（非标准明文）**：不以“现有企业”作为触发限制；对本软件计算的相关能耗指标，只要所属评价厂区位置**海拔 > 1500m**就启用海拔修正，包括新建、改建、扩建。海拔=1500m不触发。纯粉磨站的正式表3工段电耗不在海拔修正指标清单内；若软件额外展示水泥综合能耗参考等级，也可按本扩展口径使用K，结果明确标记“扩展参考”，不得代替标准第5.1/5.2的粉磨站正式判定。

## 7.2 海拔修正系数与数据要求

\[
K=1.179-0.211\times\frac{P_H}{P_0},\quad P_0=101325\ \mathrm{Pa}
\]

|变量|含义|单位|
|---|---|---|
|`K`|海拔修正系数|—|
|`P_0`|海平面环境大气压，取101325|Pa|
|`P_H`|水泥窑所在地环境大气压；对无水泥窑对象的**软件扩展参考计算**，使用该评价厂区实测环境大气压并标明来源|Pa|
|厂区海拔|严格大于1500 m时启用K|m|

海拔未超1500m时软件置 `K=1`；超1500m时需提供 `P_H>0`，缺失或无效则相关动态等级**无法判定**，不得偷偷取默认气压。原文未规定软件数据入口、测量方法或任何自动气压估算算法，软件不自行根据海拔合成气压。

|需要修正的3级阈值|基准值|海拔修正后|
|---|---:|---|
|水泥单位产品综合能耗|94 kgce/t|94K|
|熟料单位产品综合能耗|117 kgce/t|117K|
|熟料单位产品综合电耗|61 kW·h/t|61K|
|熟料单位产品综合煤耗|109 kgce/t|109K|

**1级及2级阈值不乘K；表3水泥制备工段电耗不乘K。**海拔处理属于改变限额阈值，而不是把实际能耗值乘K。软件扩展企业类型与标准正文的不同必须在用户可见依据中明确说明。

# 8. 水泥熟料比例修正

当水泥产品中熟料配比高于或低于75%时，水泥单位产品综合能耗限额值进行修正。

每变化1个百分点：

|等级|修正量|
|---|---|
|1级|1.10 kgce/t|
|2级|1.15 kgce/t|
|3级|1.20 kgce/t|

01.GB 16780-2021水泥单位产品能源消耗限额

令：

```
g = 水泥中熟料平均配比，%
Δg = g - 75
```

则：

\[ L_1=80+1.10(g-75) \]\[ L_2=87+1.15(g-75) \]

当不存在海拔修正时：

\[ L_3=94+1.20(g-75) \]

---


## 8.1 海拔修正与熟料比例修正同时发生

**原文事实**：标准第5.3条给出海拔修正、第5.4条给出熟料比例修正，但没有直接给出二者同时发生时的组合公式。

**用户已确认的软件实现约定**：先对水泥综合能耗3级基准限额进行海拔修正，再按熟料配比百分点作加法修正，原因是海拔主要影响熟料生产环节，而熟料比例调整应在之后独立反映。该解释不冒称唯一官方计算顺序；关联标准问题 `ECQ-STD-GB16780-003`。

令 `g` 为输入的百分数数值（如80表示80%），`Δg=g-75` 为**百分点差**；当海拔不超过1500m时K=1。

\[
\boxed{L_1=80+1.10(g-75)}
\]

\[
\boxed{L_2=87+1.15(g-75)}
\]

\[
\boxed{L_3=94K+1.20(g-75)}
\]

只修正水泥**综合能耗**的熟料比例阈值；熟料本身三指标、工段电耗不作75%熟料比例修正。等级比较统一使用上述最终阈值。

**例**：K=1.05、g=80，3级阈值=94×1.05+1.20×5=**104.70 kgce/t**；不是 (94+1.20×5)×1.05=105.00。当前仓库 `data/definitions/gb-16780-2021.json` 仍包含后者表达式，未来 Stage B/C 必须单独修复、配套边界测试，本次文档修改不会自动更新程序。

## 8.2 每变化1个百分点的修正量

|等级|每增减1%熟料比例的限额修正量|
|---|---|
|1级|1.10 kgce/t|
|2级|1.15 kgce/t|
|3级|1.20 kgce/t|

标准原文规定见第5.4。 01.GB 16780-2021水泥单位产品能源消耗限额


## 8.3 软件公式映射及两种百分数口径

- **判级阈值**使用百分点输入，例如 `g=80`，`g-75=5`。
- **水泥综合能耗式（8）**使用比例计算值 `g_ratio=g/100`，例如输入80后内部传递0.80。
- 不得在阈值修正时使用0.80−75，也不得在式（8）中直接把80当比例系数。
- 最终比较遵循项目现有Decimal全值比较契约，显示修约不得反向改变等级。

\[
L_1=80+1.10(g-75),\quad
L_2=87+1.15(g-75),\quad
L_3=94K+1.20(g-75).
\]

|例子|1级阈值|2级阈值|3级阈值（K=1）|
|---|---:|---:|---:|
|g=80%|85.50|92.75|100.00|
|g=75%|80.00|87.00|94.00|
|g=70%|74.50|81.25|88.00|

即使使用最终阈值，还应检查阈值顺序、输入合法性和缺失数据；严禁在数据不完整时通过占位值生成正式等级。

## 9.3 软件候选计算链（须核2019稿C.1/C.3）

设 P_sh 为**自产熟料产量**、P_shx 为**本期生产水泥消耗的熟料数量**、P_s 为水泥产量，各自独立，单位t。

1. 熟料综合煤耗：先按2021正式式（2）及余热发电式（3）计算 e_sh,base；如原始燃料包括这两项，**候选**按 e_sh,net = e_sh,base − D_fuel,kgce / P_sh 扣减。
2. 熟料综合电耗：先读取式（4）原始电量 w_sh；如尚未扣除W_fc，**候选**按 W_sh,net = (w_sh − W_fc) / P_sh 计算。
3. 熟料综合能耗：依据2021正式式（5），由**净煤耗与净电耗**得到 E_sh,net = e_sh,net + 0.1229 × W_sh,net；**不得**再整体扣减燃料或电量。
4. 水泥综合电耗：按正式式（7）使用 W_sh,net × P_shx 及其他相应电量；**不得**在式（7）汇总结果上再全额扣除W_fc。全部外购熟料W_sh按0；部分外购熟料W_sh按本企业熟料综合电耗处理。
5. 水泥综合能耗：按正式式（8）使用适用的 e_sh,net、g/100、e_h/P_s 与 0.1229×W_s；**不得**在最终E_s中再额外扣减这四项。部分外购熟料时e_sh采用本企业熟料**综合煤耗**（Issue001）。
6. 水泥制备工段电耗：按正式式（9）独立计算；窑系统四项扣除量不迁移到表3工段电耗。

以上为**实现候选解释**，不是引用公式C.1/C.3的已核转写。必须取得原稿后检查其数学结构、变量定义、分母、与余热发电扣减的关系及何时触发扣减。发现差异时先修Mapping，再批准计算规则。

## 9.4 熟料产量和水泥熟料用量必须独立

|符号|含义|主要应用|
|---|---|---|
|P_sh|本期自产熟料总产量，t|式（2）（3）（4）（5）的熟料单位分母|
|P_shx|本期企业生产水泥所耗熟料量，t|式（7）的熟料电量折算项，可与P_sh不同|
|P_s|本期水泥产品产量，t|式（6）（8）（9）的分母|
|g|水泥熟料平均配比，输入75表示75%|式（8）使用g/100；阈值修正用g−75|

不要求、也不默认 P_sh=P_shx；不能用某个总产量推断本期实际消耗熟料量。对于部分外购熟料，原文规定按本企业单位煤耗/电耗口径执行，不另外引入“把四项扣除按自产熟料占比二次分摊”的自创公式。

## 9.5 异常与追溯

- 燃料、电力扣除均要求与同一窑系统、统计期、生产线原始能耗边界一致，不得跨期/跨线混扣。
- P_sh必须>0；w_sh−W_fc不得<0；燃料对应待扣量不能超过已经计入原始燃料总量的部分。
- 余热发电扣减仅按式（3）发生一次，不与四项新字段重复。
- 分项输出四个原始填写值（含未填状态）、两种单位各自合计、熟料煤耗/电耗扣前与扣后结果及计算链。
- 生产线/指标独立判定；存在无法核准的扣除边界时，相应指标标记不能正式判级，不可给虚假的完整结论。

# 16. 水泥单位产品综合能耗

> 在四字段分项口径下，式（8）使用适用的熟料净煤耗e_sh、由式（7）算出的W_s和水泥制备系统燃料e_h；不得在最终E_s上再次扣除窑系统燃料/电量。此候选计算链须对照2019征求意见稿C.1/C.3核实。

## 16.1 公式

\[ E_s = e_{sh}\times g + \frac{e_h}{P_s} + 0.1229\times W_s \]

其中：

|参数|含义|单位|
|---|---|---|
|`E_s`|水泥单位产品综合能耗|kgce/t|
|`e_sh`|熟料单位产品综合煤耗|kgce/t|
|`g`|统计期内水泥中熟料平均配比|%|
|`e_h`|水泥制备系统（包括水泥混合材烘干）所消耗燃料折算标准煤量|kgce|
|`P_s`|水泥产品总产量|t|
|`W_s`|水泥单位产品综合电耗|kW·h/t|

01.GB 16780-2021水泥单位产品能源消耗限额

### 软件实现特别注意


其中标准将：

```
g
```

定义为统计报告期内水泥中熟料平均配比，单位：

```
%
```

01.GB 16780-2021水泥单位产品能源消耗限额

## 软件输入规则

用户界面采用通常的百分数输入方式：

```
75
```

表示：

```
75%
```

而不是要求用户输入：

```
0.75
```

## 计算层强制转换

计算时必须统一转换：

\[ g_{calc}=\frac{g_{input}}{100} \]

例如：

```
用户输入：

g = 75

计算层：

g_calc = 75 / 100
       = 0.75
```

因此软件实际计算逻辑应为：

\[ E_s = e_{sh}\times\frac{g}{100} + \frac{e_h}{P_s} + 0.1229W_s \]

### 强制规则

该转换必须：

```
在计算内核自动完成
```

不得：

```
要求用户自行把75%换成0.75
```

也不得让不同页面或不同导入方式采用不同口径。

建议固化为统一数据契约：

```
界面/Excel/API输入：
g = 75

Canonical业务值：
g = 75 %

计算内部值：
g_ratio = Decimal("0.75")
```

这样 GUI 手工录入、Excel 导入和后续批量计算的含义始终一致。

3. 独立录入并验证熟料生产量P_sh和水泥熟料消耗量P_shx，水泥产量P_s另列。不得以P_sh=P_shx作为隐含假设；多线企业分线统计。
4. 四个窑系统扣除字段分别以tce、kW·h录入，默认**空白**，浅色placeholder统一为“若已扣除，则不填”。检验本期边界、是否已扣除、非负、未交叉重复录入。
5. 按2021正式版式（2）～（9）计算。燃料、电力分别扣减的位置依据第9.3节**待核准软件候选链**，须将2019稿C.1/C.3核对结果写入正式Stage B；净熟料煤耗/电耗参与式（5）（7）（8），不在最终综合能耗再次整体扣。
6. 海拔严格>1500m时按已确认扩展口径处理表1/表2的四项3级阈值，表3不修正；水泥综合能耗按L1=80+1.10(g-75)、L2=87+1.15(g-75)、L3=94K+1.20(g-75)。百分数g=75表示75%，式（8）使用g/100。
7. 每项指标独立判级，不合成为熟料“总等级”。缺失只影响存在依赖关系的指标；其他完整指标仍可正常显示。超出3级是完整有效等级，NOT_APPLICABLE不计入缺项。
8. **Q1=A：任何适用指标不完整时，只展示部分计算预览，不保存完整正式评价记录**。该检查在Application的保存动作之前实现，不能只在UI隐藏按钮。
9. 结果追踪应包括实际输入、四类扣除值及空白状态、扣前/扣后中间量、阈值、等级、标准条款与两项已登记Standard Issue。不得将2019征求意见稿候选解释冒充2021标准原文。

# 26. 实现时需要特别注意的两个问题

## 26.1 熟料比例 `g` 的百分数问题

标准式（8）写为：

\[ E_s=e_{sh}\times g+\frac{e_h}{P_s}+0.1229W_s \]

同时定义：

```
g——统计期内水泥企业水泥中熟料平均配比，%
```

因此软件界面如果输入：

```
75%
```

实际计算必须使用：

```
0.75
```

建议把这个转换固化在计算层，不让用户自己转换。

---


## 26.2 海拔修正与熟料比例修正同时发生

GB 16780—2021第5.3和5.4分别规定海拔修正和熟料比例修正，但没有规定两项修正同时发生时的唯一组合顺序。

本软件经用户确认的**实现约定**：

\[
L_3=94K+1.20(g-75)
\]

先对熟料相关的水泥综合能耗3级基准值94施加海拔系数，再独立叠加百分点配比修正。海拔≤1500m时`K=1`。不属于标准原文指定的组合公式，见台账`ECQ-STD-GB16780-003`。

**注意**：V1.1仍为软件实现前的映射文件；旧JSON存在不同公式，未来修改必须由Rule、Calculator和边界Golden测试共同验证。

## 27. 标准判定核心结构

最终可以把本标准抽象成四类评价对象：

|评价对象|核心指标|等级|
|---|---|---|
|水泥|水泥单位产品综合能耗|1/2/3级|
|熟料|综合能耗 + 综合煤耗 + 综合电耗|1/2/3级|
|水泥制备工段|工段电耗|1/2/3级|
|项目准入/现有企业限定|上述指标对应等级|现有≥3级；新改扩≥2级|

这部分是整个 **GB 16780—2021 软件化映射的主骨架**。标准的限额等级原值见表1～表3。 01.GB 16780-2021水泥单位产品能源消耗限额

我建议后续开发时，**不要把 GB 16780—2021 做成一个简单的“输入一个能耗值→查表判级”标准**。它实际上属于较复杂型标准：有多指标、企业属性、外购熟料、海拔修正、熟料比例修正、余热发电扣减、协同处置以及多生产线分摊。最适合把它归入你前面确定的“复杂型新建评价”框架。
