# 4. 能耗限额等级映射

标准规定**1级能耗最低，2级次之，3级最高**。 01.GB 16780-2021水泥单位产品能源消耗限额

## 4.1 水泥单位产品综合能耗

### 表1 水泥单位产品综合能耗限额等级

下列为**未发生海拔、熟料比例修正时的基准判级示例**。发生修正时，以第8.1节生成的最终有效阈值 `L1/L2/L3` 判级，不得仍固定比较80/87/94。

```

→ 1级

80 < E_s ≤ 87
→ 2级

87 < E_s ≤ 94
→ 3级

→ 未达到3级
```

## 4.2 熟料单位产品能耗

### 表2 熟料单位产品综合能耗、综合电耗与综合煤耗限额等级

|指标|单位|1级|2级|3级|
|---|---|---|---|---|
|熟料单位产品综合能耗 `E_sh`|kgce/t|≤100|≤107|≤117|
|熟料单位产品综合电耗 `W_sh`|kW·h/t|≤48|≤57|≤61|
|熟料单位产品综合煤耗 `e_sh`|kgce/t|≤94|≤100|≤109|

标准将三个指标并列规定，并分别设置1级、2级、3级限额。 01.GB 16780-2021水泥单位产品能源消耗限额

### 判定原则

三个指标**分别判级，分别输出评价结论**，不合成为一个所谓“熟料最终等级”。

例如：

|指标|实际值|判定结果|
|---|---|---|
|熟料单位产品综合能耗|103 kgce/t|2级|
|熟料单位产品综合电耗|46 kW·h/t|1级|
|熟料单位产品综合煤耗|105 kgce/t|3级|

软件输出应保持：

```
熟料单位产品综合能耗：2级
熟料单位产品综合电耗：1级
熟料单位产品综合煤耗：3级
```

**不再输出：**

```
熟料最终等级：3级
```

> 标准表2虽然同时列出了三项熟料能耗指标，但没有规定将三项判级结果进一步合成为一个“熟料综合等级”，因此软件不自行增加这一评价概念。

# 7. 海拔修正

## 7.1 标准原文与软件适用范围分别记录

**标准原文事实（§5.3）**：海拔修正明确描述为“生产水泥和水泥熟料产品的现有企业”、位置海拔严格大于1500m时，表1及表2相关四项**3级限额值**乘以修正系数K；标准并未规定所有企业类型普遍适用。

**用户已确认的软件扩展口径（非标准明文）**：不以“现有企业”作为触发限制；对本软件计算的相关能耗指标，只要所属评价厂区位置**海拔 > 1500m**就启用海拔修正，包括新建、改建、扩建。海拔=1500m不触发。纯粉磨站的正式表3工段电耗不在海拔修正指标清单内；若软件额外展示水泥综合能耗参考等级，也可按本扩展口径使用K，结果明确标记“扩展参考”，不得代替标准第5.1/5.2的粉磨站正式判定。

## 7.2 海拔修正系数与数据要求

\[
K=1.179-0.211\times\frac{P_H}{P_0},\quad P_0=101325\ \mathrm{Pa}
\]

|变量|含义|单位|
|---|---|---|
|`K`|海拔修正系数|—|
|`P_0`|海平面环境大气压，取101325|Pa|
|`P_H`|水泥窑所在地环境大气压；对无水泥窑对象的**软件扩展参考计算**，使用该评价厂区实测环境大气压并标明来源|Pa|
|厂区海拔|严格大于1500 m时启用K|m|

海拔未超1500m时软件置 `K=1`；超1500m时需提供 `P_H>0`，缺失或无效则相关动态等级**无法判定**，不得偷偷取默认气压。原文未规定软件数据入口、测量方法或任何自动气压估算算法，软件不自行根据海拔合成气压。

|需要修正的3级阈值|基准值|海拔修正后|
|---|---:|---|
|水泥单位产品综合能耗|94 kgce/t|94K|
|熟料单位产品综合能耗|117 kgce/t|117K|
|熟料单位产品综合电耗|61 kW·h/t|61K|
|熟料单位产品综合煤耗|109 kgce/t|109K|

**1级及2级阈值不乘K；表3水泥制备工段电耗不乘K。**海拔处理属于改变限额阈值，而不是把实际能耗值乘K。软件扩展企业类型与标准正文的不同必须在用户可见依据中明确说明。

# 8. 水泥熟料比例修正

当水泥产品中熟料配比高于或低于75%时，水泥单位产品综合能耗限额值进行修正。

每变化1个百分点：

|等级|修正量|
|---|---|
|1级|1.10 kgce/t|
|2级|1.15 kgce/t|
|3级|1.20 kgce/t|

01.GB 16780-2021水泥单位产品能源消耗限额

令：

```
g = 水泥中熟料平均配比，%
Δg = g - 75
```

则：

\[ L_1=80+1.10(g-75) \]\[ L_2=87+1.15(g-75) \]

当不存在海拔修正时：

\[ L_3=94+1.20(g-75) \]

---


## 8.1 海拔修正与熟料比例修正同时发生

**原文事实**：标准第5.3条给出海拔修正、第5.4条给出熟料比例修正，但没有直接给出二者同时发生时的组合公式。

**用户已确认的软件实现约定**：先对水泥综合能耗3级基准限额进行海拔修正，再按熟料配比百分点作加法修正，原因是海拔主要影响熟料生产环节，而熟料比例调整应在之后独立反映。该解释不冒称唯一官方计算顺序；关联标准问题 `ECQ-STD-GB16780-003`。

令 `g` 为输入的百分数数值（如80表示80%），`Δg=g-75` 为**百分点差**；当海拔不超过1500m时K=1。

\[
\boxed{L_1=80+1.10(g-75)}
\]

\[
\boxed{L_2=87+1.15(g-75)}
\]

\[
\boxed{L_3=94K+1.20(g-75)}
\]

只修正水泥**综合能耗**的熟料比例阈值；熟料本身三指标、工段电耗不作75%熟料比例修正。等级比较统一使用上述最终阈值。

**例**：K=1.05、g=80，3级阈值=94×1.05+1.20×5=**104.70 kgce/t**；不是 (94+1.20×5)×1.05=105.00。当前仓库 `data/definitions/gb-16780-2021.json` 仍包含后者表达式，未来 Stage B/C 必须单独修复、配套边界测试，本次文档修改不会自动更新程序。

## 8.2 每变化1个百分点的修正量

|等级|每增减1%熟料比例的限额修正量|
|---|---|
|1级|1.10 kgce/t|
|2级|1.15 kgce/t|
|3级|1.20 kgce/t|

标准原文规定见第5.4。 01.GB 16780-2021水泥单位产品能源消耗限额


## 8.3 软件公式映射及两种百分数口径

- **判级阈值**使用百分点输入，例如 `g=80`，`g-75=5`。
- **水泥综合能耗式（8）**使用比例计算值 `g_ratio=g/100`，例如输入80后内部传递0.80。
- 不得在阈值修正时使用0.80−75，也不得在式（8）中直接把80当比例系数。
- 最终比较遵循项目现有Decimal全值比较契约，显示修约不得反向改变等级。

\[
L_1=80+1.10(g-75),\quad
L_2=87+1.15(g-75),\quad
L_3=94K+1.20(g-75).
\]

|例子|1级阈值|2级阈值|3级阈值（K=1）|
|---|---:|---:|---:|
|g=80%|85.50|92.75|100.00|
|g=75%|80.00|87.00|94.00|
|g=70%|74.50|81.25|88.00|

即使使用最终阈值，还应检查阈值顺序、输入合法性和缺失数据；严禁在数据不完整时通过占位值生成正式等级。


# 9. 协同处置和替代燃料（用户确认的简化录入）

## 9.1 标准原文事实与简化范围

§5.5要求在相关能耗指标限额评价中扣除协同处置消耗的能源量和替代燃料量；§6.1.1及§6.1.2要求单独统计。原文没有提供能够对所有现场情况、能源形式和指标直接通用的一套完整扣除公式。

**软件本阶段只设两个手填数值，不再增加明细折算表、额外必填说明、勾选状态或复杂分配接口：**

|字段/建议key|单位|录入|默认|校验|
|---|---|---|---|---|
|协同处置能源能耗 `deduction.co_processing_tce`|tce|手动输入|0|非负有限十进制数|
|替代燃料折标煤量 `deduction.alternative_fuel_tce`|tce|手动输入|0|非负有限十进制数|

二者为同一评价周期、同一评价生产线及同一对应能耗统计边界内**已经计入原始能源消耗**的可扣除折标煤量。由用户按其掌握的计量/折标依据提供，不由程序自动估算。

\[
D_{\mathrm{kgce}}=1000\,(C_{\mathrm{tce}}+F_{\mathrm{tce}})
\]

## 9.2 扣除方法与单位约束

1. 先按原文式（2）—（9）计算**扣除前**指标，再对与该扣除额统计边界一致的**综合能耗指标**作一次性折标煤总量扣除。例如对应产量为P(t)的评价对象：`E_扣除后=E_扣除前-D_kgce/P`，单位kgce/t。
2. 熟料综合能耗或水泥综合能耗可在边界明确时使用这一简化修正；同一能源量不得在“熟料→水泥”计算链中重复全额扣除。
3. **不得**将tce直接从kW·h中相减；仅有这两个总量字段，无法判定综合煤耗与综合电耗各自应扣多少。涉及这两项但缺乏分类归属证据时，展示未完成分类扣除的提示，相关正式完整性状态为`UNDETERMINED`，不宣称已实现§5.5全部指标的正式扣除。
4. 对于表3水泥制备工段电耗，两个tce输入不改变电耗(kW·h/t)值。
5. 输入已经扣除协同处置/替代燃料后的净能耗时，禁止重复再减；扣除量超出所对应原始能源总量时阻断；产量=0或缺失时不得除法计算。
6. 多线企业按生产线/评价边界分别录入这**相同的两个字段**，不引入第三个输入项目，不能直接把一个全厂扣除量复制给每一条线。

**实现属性**：此处是用户批准的阶段性简化软件口径，不是对§5.5完整逐指标折算办法的声明。若将来需要对综合煤耗、综合电耗分别正式扣除，应另行进行Stage B业务设计；本次不向标准问题台账新增相关编号。

## 9.3 计算结果和审计显示

输出扣除前的能耗、两项手填扣除值（tce）、合计扣除值（tce与kgce）、扣除后综合能耗(kgce/t)、是否缺少分项依据的提示，能够追踪同一周期和生产线。扣除量为0时不改变原始值。

# 10. 熟料单位产品综合煤耗计算

> 本节式（2）为**标准原文的熟料综合煤耗基础公式**；第9节两个tce输入属于独立的综合能耗简化扣除，不得未经能源类别区分就直接从本公式的燃料量或结果中再扣一次。

## 10.1 公式

\[ e_{sh} = \frac{\sum_{i=1}^{n}(m_i\times Q_{idw})} {Q_{BM}\times P_{sh}} - E_{he} \]

其中：

|参数|含义|单位|
|---|---|---|
|`e_sh`|熟料单位产品综合煤耗|kgce/t|
|`n`|消耗能源品种数量|—|
|`m_i`|第i种燃料消耗总量|kg|
|`Q_idw`|第i种燃料加权平均低位发热量|kJ/kg|
|`Q_BM`|每千克标准煤发热量|kJ/kgce|
|`P_sh`|符合GB/T 21372要求的水泥熟料产量|t|
|`E_he`|单位熟料余热发电折算标准煤量|kgce/t|

# 11. 余热发电扣减

## 11.1 公式

\[ E_{he} = 0.1229\times \frac{w_{he}-w_0}{P_{sh}} \]

其中：

|参数|含义|单位|
|---|---|---|
|`0.1229`|每千瓦时电力折合标准煤量|kgce/(kW·h)|
|`w_he`|统计报告期内余热电站发电量|kW·h|
|`w_0`|统计报告期内余热电站自用电量|kW·h|
|`P_sh`|熟料产量|t|

### 净余热发电量

```
w_net = w_he - w_0
```

# 16. 水泥单位产品综合能耗

> 式（8）先计算扣除前水泥综合能耗；若本线水泥评价边界存在第9节的有效扣除量，则使用`E_s,净=E_s,原-D_kgce/P_s`进行综合能耗判级。已在熟料侧扣过的同一能源总量不得在水泥侧再次全额扣除。

## 16.1 公式

\[ E_s = e_{sh}\times g + \frac{e_h}{P_s} + 0.1229\times W_s \]

其中：

|参数|含义|单位|
|---|---|---|
|`E_s`|水泥单位产品综合能耗|kgce/t|
|`e_sh`|熟料单位产品综合煤耗|kgce/t|
|`g`|统计期内水泥中熟料平均配比|%|
|`e_h`|水泥制备系统（包括水泥混合材烘干）所消耗燃料折算标准煤量|kgce|
|`P_s`|水泥产品总产量|t|
|`W_s`|水泥单位产品综合电耗|kW·h/t|

01.GB 16780-2021水泥单位产品能源消耗限额

### 软件实现特别注意


其中标准将：

```
g
```

定义为统计报告期内水泥中熟料平均配比，单位：

```
%
```

01.GB 16780-2021水泥单位产品能源消耗限额

## 软件输入规则

用户界面采用通常的百分数输入方式：

```
75
```

表示：

```
75%
```

而不是要求用户输入：

```
0.75
```

## 计算层强制转换

计算时必须统一转换：

\[ g_{calc}=\frac{g_{input}}{100} \]

例如：

```
用户输入：

g = 75

计算层：

g_calc = 75 / 100
       = 0.75
```

因此软件实际计算逻辑应为：

\[ E_s = e_{sh}\times\frac{g}{100} + \frac{e_h}{P_s} + 0.1229W_s \]

### 强制规则

该转换必须：

```
在计算内核自动完成
```

不得：

```
要求用户自行把75%换成0.75
```

也不得让不同页面或不同导入方式采用不同口径。

建议固化为统一数据契约：

```
界面/Excel/API输入：
g = 75

Canonical业务值：
g = 75 %

计算内部值：
g_ratio = Decimal("0.75")
```

这样 GUI 手工录入、Excel 导入和后续批量计算的含义始终一致。

## 17.1 全部采用外购熟料

当企业全部采用外购熟料生产水泥时，式（8）中的 `e_sh` 按0计算。

### 水泥综合能耗

**原文冲突**：§6.2.5关于部分外购熟料的文字将式（8）的 `e_sh` 称为本企业熟料单位产品“综合能耗”数据，而§6.2.1中 `e_sh` 是**综合煤耗**；§6.2.3中综合能耗的符号另为 `E_sh`。

**用户已确认的内部校正规则**：把§6.2.5中的“综合能耗”视为疑似文字笔误，式（8）在**部分外购熟料**情况下使用本企业熟料单位产品**综合煤耗`e_sh`**，不得使用`E_sh`，以防把熟料电耗再计算一次。此决定无需每次计算请求用户选择。

**解释状态**：软件内部处理已确认；标准文本仍保留原样，尚未取得国家标准勘误/发布机构书面解释，不得标记为官方确认。已登记正式问题 `ECQ-STD-GB16780-001`，用于后续追溯、测试和版本更新。

# 22. 软件判定流程映射

1. 按标准§1、§5.1–5.2确认评价对象、生产模式及适用指标（项目类型的3级/2级要求仍按原文）。
2. 按统计周期和生产线读取原始计量数据，检查数据完整、产量为正、单位合法。
3. 按§6.2式（2）—（9）计算**扣除前**能耗和电耗，并校验余热自用电不超过余热发电。
4. 读取**两个**手动tce扣除值，校验边界、非负、未重复扣除。仅对可明确归属的综合能耗实行第9节简化扣除；煤耗/电耗无法分类时标识未完成分类扣除。
5. 计算海拔系数K（仅海拔严格>1500m触发，本软件不限现有/新改扩），按用户确定顺序计算`L3=94K+1.20(g-75)`，并计算L1/L2；其余相关3级按第7节乘K。
6. 将扣除后且可正式评价的指标，与其**最终有效阈值**进行全值比较，输出1/2/3级或超出3级；区分`NOT_APPLICABLE`与`UNDETERMINED`。
7. 各熟料指标分别判级，不凭空生成“熟料总等级”；企业限定值/准入符合性依§5.1–5.2逐项检查。
8. 结果解释分别显示**标准原文要求、用户批准的软件扩展、计算输入与公式、仍未满足的正式评价条件**；记录关联Issue 001/003。

# 26. 实现时需要特别注意的两个问题

## 26.1 熟料比例 `g` 的百分数问题

标准式（8）写为：

\[ E_s=e_{sh}\times g+\frac{e_h}{P_s}+0.1229W_s \]

同时定义：

```
g——统计期内水泥企业水泥中熟料平均配比，%
```

因此软件界面如果输入：

```
75%
```

实际计算必须使用：

```
0.75
```

建议把这个转换固化在计算层，不让用户自己转换。

---


## 26.2 海拔修正与熟料比例修正同时发生

GB 16780—2021第5.3和5.4分别规定海拔修正和熟料比例修正，但没有规定两项修正同时发生时的唯一组合顺序。

本软件经用户确认的**实现约定**：

\[
L_3=94K+1.20(g-75)
\]

先对熟料相关的水泥综合能耗3级基准值94施加海拔系数，再独立叠加百分点配比修正。海拔≤1500m时`K=1`。不属于标准原文指定的组合公式，见台账`ECQ-STD-GB16780-003`。

**注意**：V1.1仍为软件实现前的映射文件；旧JSON存在不同公式，未来修改必须由Rule、Calculator和边界Golden测试共同验证。

## 27. 标准判定核心结构

最终可以把本标准抽象成四类评价对象：

|评价对象|核心指标|等级|
|---|---|---|
|水泥|水泥单位产品综合能耗|1/2/3级|
|熟料|综合能耗 + 综合煤耗 + 综合电耗|1/2/3级|
|水泥制备工段|工段电耗|1/2/3级|
|项目准入/现有企业限定|上述指标对应等级|现有≥3级；新改扩≥2级|

这部分是整个 **GB 16780—2021 软件化映射的主骨架**。标准的限额等级原值见表1～表3。 01.GB 16780-2021水泥单位产品能源消耗限额

我建议后续开发时，**不要把 GB 16780—2021 做成一个简单的“输入一个能耗值→查表判级”标准**。它实际上属于较复杂型标准：有多指标、企业属性、外购熟料、海拔修正、熟料比例修正、余热发电扣减、协同处置以及多生产线分摊。最适合把它归入你前面确定的“复杂型新建评价”框架。
