## 4. 核算边界与基本公式（MAP-GB38263-2019-003）

§3.1、§6.1，p1、3—4/PDF3、5—6：从原材料进厂且能源经计量进入工序开始，到成品计量出库，覆盖生产、辅助及附属系统的能源消耗、生产耗能工质所耗能源和损失；不计基建/技改项目建设、回收利用和向外输出的能源量，避免重复统计。各产品原料边界不同，但均为上述进厂至出库边界：

| 产品 | 原料与构件边界摘要 |
|---|---|
| 桩 | 水泥、掺合料、骨料、外加剂、PC棒、端板、桩套箍、钢筋等 |
| 电杆 | 水泥、掺合料、骨料、外加剂、连接法兰、钢筋等 |
| 排水管 | 水泥、骨料、外加剂、钢筋等 |
| 钢筒混凝土管 | 水泥、骨料、外加剂、钢板（含承插口环）、钢筋等 |
| 加气混凝土 | 水泥、砂、粉煤灰、生石灰、石膏、铝粉膏、磷石膏等 |
| 硅酸钙板 | 水泥、增强纤维、硅质及钙质材料等 |
| 衬砌管片 | 水泥、骨料、外加剂、钢筋、连接件、密封材料等 |

§6.1.1.2：折标热值以报告期实测为准，无实测条件用GB/T2589参考系数。本文无自带系数附录，不从现有JSON或其他标准复制系数作为本标准明文。§6.2要求产品分别统计，计量器具遵循GB17167。

§6.3.2式(1)：`E = Σ(e_i × ρ_i)`。E为报告期综合能耗（kgce），e_i为各能源实物量，ρ_i为对应折标系数。
§6.3.3式(2)：`E_g = E / G`。G为报告期合格产量（m³），E_g为kgce/m³。

原文将e_i单位统一写作kg，涉及电力/热力时存在单位对应问题；见 **ECQ-STD-GB38263-001**。候选单位设计应把每项实物量和同量纲系数配对，不允许将所有能源当质量或盲目二次折标。G=0、负数、缺测和跨产品分摊的正式处理留Stage B，不能返回伪造等级。

## 5. 寒冷地区煤耗修正（MAP-GB38263-2019-004）

§3.3 p2/PDF4的煤耗覆盖蒸汽或用于生产蒸汽的燃料，不能仅按字面理解为原煤。§6.3.4，p4—5/PDF6—7：

| 原式 | 计算关系 | 含义 |
|---|---|---|
| (3) | E′_gM = (E′_M / G′) / f | 冬期单位产品煤耗修正值；G′冬期合格产量m³ |
| (4) | E′_M = Σ(e_Mi × ρ_i) | 冬期煤耗汇总；原文字单位问题关联001 |
| (5) | f = (t − t1) / (t − t0) | t恒温养护温度、t1冬期平均温度、t0年平均温度，均℃；t1和t0均采用当地气象部门数据 |
| (6) | E_gM = [E′_gM × m + Σ(i=1…12−m) E_gMi] / 12 | m为冬期月数，E_gMi为其余各月单位产品煤耗 |

式(6)是原文按月数平均的结构，不能为适配现有E/G而擅改为产量加权。原文要求寒冷地区煤耗修正，但修正全年煤耗与其他能源汇合的综合公式、寒冷地区/冬期判据、停产月份及非全年期间未在本文闭合，见 **ECQ-STD-GB38263-002**。本草稿不选定内部处理决定；不能把全部能耗除f。冬期蒸汽和制汽燃料不得重复计入。
