## 5. 参数、公式与修正

### 5.1 实际能耗（MAP-GB21342-2025-018）

§6.2式（3），p4/PDF8：

`E_actual = (e_yl + e_jg - e_jt - e_jf - e_yr) / p_JT`

- e_yl：原料煤携带有效能量。
- e_jg：加工耗能；煤气（焦炉/高炉/转炉/驰放气等）、电、蒸汽、水、压缩空气、氧气、氮气等有效能量。
- e_jt：焦炭产品携带能量；e_jf：净化回收的焦炉煤气、煤焦油、粗苯等化工产品携带能量。
- e_yr：干熄焦、荒煤气显热回收等余热利用装置回收有效能量，以蒸汽热焓折煤；p_JT为干全焦产量。

满足§6.1.1完整外属且未计入条件时，`E_eval=E_actual+26`，其他已明确不触发情形为`E_eval=E_actual`。部分外属情形待Issue决定。标准在§5.3也使用E_JT表示“限额”，本文用E_actual/E_eval及L明确区分，**不改写原公式符号**。

技术判断：内部煤气再利用、外送和回收流应按统计边界保持能量账一致，不能同时以总回收和净外供两种口径重复抵扣；不在本次发明每股能流的强制输入表。

## 6. 判定、异常与输出（MAP-GB21342-2025-029）

标准事实：各指标≤对应修正限额即满足该项，等号属满足侧；现有企业限定值看L3，新/扩/改建准入看L2；1级脚注限定现有企业。**等级符合性与建设项目准入不是同一个输出。**

技术建议：先逐项输出适用性及`E_eval≤Lk`真假，再决定单一等级展示；不得排序、取max或强制L1≤L2来“修复”表格。1、2级基值相等，炉龄修正使L1>L2；单一等级和准入关系见Issue 001，未批准前不宣称任意“1级”必然满足2级准入。所有T−δ/T/T+δ比较沿用项目Numeric全值语义。

| 情形 | 原文/技术判断 | 候选处理（非已批准新增阻断） |
|---|---|---|
| 不属常规焦炉 | §1不在适用范围 | 不适用，保留原因 |
| 无法确定工艺或统计边界 | 分类/计算依据不足 | 无法判定受影响项；不冒称超限 |
| p_JT=0 | 式（3）除零无定义 | 不能计算单位能耗；负产量需纠错 |
| 必需能流数据缺失、非有限或单位不一致 | 无法可靠执行式（3） | 指明缺失/错误，不将缺失填0 |
| 实际能耗为负 | 原文未设置零下限 | 先核查边界/抵扣；不擅自截为0或新建业务最低限 |
| 表外挥发分、部分外属、干湿混合工况 | 原文处理不完备，见§7 | 保留已可确定部分，待解释相关项；不自动宣布全标准不适用 |
| 已提供统计口径一致的直接值 | 不必重新要求所有分项录入 | Stage B评估直接/明细双入口最小必要性，防重复+26 |

建议最终输出：统计范围及报告期、干全焦产量与实际能耗、26调整是否适用及计入阶段、原始限额/每项修正/修正限额、逐等级适用性与比较结果、限定值或准入值结论、未决事项、来源定位及规则/Numeric版本。普通用户展示与技术审计分层；本次不规定新UI。
